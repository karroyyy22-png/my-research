# 实验：DGM4 图像定位任务的性质分析

- **日期**：2026-09-13（初步分析）；2026-10-07 在 train/val/test 三个划分上全量重算
- **负责人**：wanhongz
- **代码版本**：纯数据分析，不依赖 ASAP 代码。重算用的脚本是 2026-10-07 实验的 `analyze_failures.py`（`check_boxes` 函数），见 `experiments/2026-10-07-asap-failure-analysis/scripts/`；跨划分的统计是一段临时脚本，结果抄录在本文。
- **关联数据**：`/nas/data_2/wanhongz/datasets/DGM4/metadata/{train,val,test}.json`，用到的字段是 `fake_image_box` 和 `mtcnn_boxes`，都是原图像素 xyxy 整数。

## 目的
在设计图像定位的改进方案之前，先弄清楚 DGM4 的"图像定位"到底是什么任务：是自由回归一个框，还是在有限的候选里做选择？这决定了评价指标应该怎么定，以及什么样的基线才有意义。

## 方法
对每个带 `fake_image_box` 的伪造样本，检查以下几点：
- gt 框和 `mtcnn_boxes` 中的框是否逐元素相等，以及有几个相等；
- 每张图的 mtcnn 人脸数；
- mtcnn 框的排列顺序和面积的关系；
- gt 框在候选框中的位置。

## 参数配置
没有参数，不写 config.yaml。

## 结果

| 划分 | 样本总数 | 带 gt 框的伪造样本 | gt 恰好等于 1 个 mtcnn 框 | 人脸数 2 / 3 / 4 / 5 |
|---|---|---|---|---|
| train | 208184 | 84295 | **100%** | 49466 / 19156 / 9986 / 5687 |
| val | 22126 | 11934 | **100%** | 6925 / 2689 / 1469 / 851 |
| test | 50705 | 26904 | **100%** | 15909 / 6047 / 3186 / 1762 |

- **gt 框 100% 恰好等于某一个 mtcnn 框**，三个划分里都没有例外，也没有一个 gt 同时等于两个候选框的情况。
- **带框的伪造样本都有 2–5 张 mtcnn 人脸**，没有单脸图。orig 和纯文本篡改的图同样至少有 2 张脸。在 test 上，平均每图 2.66 张脸。
- **mtcnn 框基本按面积降序排列**：test / val / train 分别有 93.96% / 94.42% / 94.27% 的样本完全按面积降序；第一个框就是最大框的样本占 96.95% / 97.21% / 97.04%。
- **test 上各基线的严格选对率**（被选框等于 gt 才算对）：

| 基线 | 全部带框 | face_swap | face_attribute |
|---|---|---|---|
| 随机选（期望值 mean(1/n)） | 41.33 | 41.16 | 41.32 |
| 总选第一个框 | 65.85 | 59.35 | 73.37 |
| 总选最大框（gt 恰为最大脸的比例；面积并列算错） | 66.19 | 59.85 | 73.44 |
| ASAP（实验 2026-10-07） | 84.52 | 82.04 | 86.57 |

（单位 %。）

## 分析与结论
- **DGM4 的图像定位实质上是候选选择问题**：在 2–5 个 mtcnn 人脸里选出被篡改的那张。因为 gt 一定是某个候选框，选对就等于 IoU=1。所以"严格选对率"比 IoU 均值更能反映定位能力；IoU 均值会混入部分重叠的贡献，官方的全体 IoU 均值还包括了非人脸样本。
- **"第一个框"和"最大框"两个基线几乎相等**（65.85% 对 66.19%），原因是 mtcnn 框基本按面积降序排列，97% 的样本里第一个框就是最大框。
- **"FS 换掉的是最大的脸"这个说法不成立**：face_swap 的 gt 是最大脸的比例只有 59.85%，face_attribute 反而更高（73.44%）。
- **以前记录的两个数要改正**：
  - 9/13 记录的"第一个框 65.90%"是第一个框和 gt 的 IoU 均值，严格选对率是 65.85%。差的 0.053 个百分点，来自 278 个第一个框和 gt 部分重叠的样本（详见实验 2026-09-13-omnifd-boxselect-eval）。
  - 当时作为 ASAP 对照的 74.43%，是官方 IoU 均值，不是选对率。

## 下一步
后续所有定位方法（包括计划中的逐脸分类器）都用严格选对率评估，并同时报告随机、第一个框、最大框和 ASAP 四个基线，按人脸数和人脸尺寸分桶。
